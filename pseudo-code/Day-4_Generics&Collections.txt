Pseudo-code: Digital Wallet Transactions Report
1. Class Transaction { id, merchant, month, amount }
2. List<Transaction> transactions
3. Use stream:
    transactions.stream()
        .collect(groupingBy(merchant,
             groupingBy(month,
                 summarizingDouble(amount)
             )
        ))
4. Output report with total amount per merchant per month
