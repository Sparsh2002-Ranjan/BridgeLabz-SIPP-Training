Pseudo-code: Library Book Filter
1. Class Book { title, year, rating }
2. List<Book> books
3. Use stream:
    books.stream()
         .filter(book.year > 2015)
         .filter(book.rating > 4.5)
         .collect(toList())
4. Print filtered books
